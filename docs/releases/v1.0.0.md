# DClutter for Windows 1.0.0 — Swipe to clean your files, on Windows

DClutter started on the Mac. People asked for it on Windows, so here it is:
the same one-file-at-a-time way through a Downloads folder full of undecided
files, rebuilt for Windows. It has every feature of the macOS app, 1.1.0, and
works the way Windows does.

## What's in it

- **One file at a time, most actionable first.** Files are ranked by the same
  scoring as on macOS: size, how stale they are, whether they came from a
  download, redundant copies, and archives you already extracted. Both apps
  check that ranking against the same shared test cases.
- **Keep, Stage, Skip, File, Rename.** Stage marks a file for trash, and
  nothing is deleted until you review the list and confirm. Even then it goes
  to the **Recycle Bin**, never straight to deletion, and DClutter refuses to
  delete anything on drives without one, such as network shares. File moves a
  file into one of up to three folders right away. Rename it with `↓` or `F2`.
- **Everything can be undone,** including moves and renames, and the session
  picks up where you left off after you close the app. Each folder you sort
  keeps its own session. **Start Over** returns a folder's files to undecided
  and moves the files you filed back.
- **Previews like File Explorer's:** videos, PowerPoint slides, folder
  contents, and the first page of every PDF, even without a PDF reader
  installed.
- **Touchpad swipes:** two fingers right to keep, left to stage. Swipe up,
  slide across and let go to file into a folder. You can also drag the card
  with a mouse or a finger.
- **Keyboard first:** `→` `←` `Space` `↑` `1`–`3` `Ctrl+Z` and more. Hold an
  arrow to move through files at a pace you set in Settings (`Ctrl+,`).

## Made for Windows

- Download sources come from Windows' own "downloaded from the internet"
  marker on each file.
- Windows doesn't reliably record when a file was last opened, so cards show
  when it was **modified** instead, and ranking uses that.
- Filing never overwrites anything. A name that's taken gets numbered the way
  File Explorer does: `Report (2).pdf`.
- A file another app has open gets a moment to be released, and if it's still
  open, DClutter tells you which app has it.
- Touchpad swipes read the touchpad itself, so a swipe starts when your
  fingers touch and ends when they lift, as on the Mac. Windows' own scrolling
  can't tell an app either of those things.

## Install

Download **DClutter_1.0.0_x64-setup.exe** and run it. Windows 10 or 11, 64-bit.
An **.msi** is also attached for managed installs.

The installer isn't code-signed yet, so Windows SmartScreen will probably say
"Windows protected your PC". Click **More info**, then **Run anyway**. It installs
for your account only and needs no administrator rights. The
[README](https://github.com/RokiTheWise/DClutter-Windows#install) explains why the
warning appears, and how to build the app yourself instead.

## Known limits

- No automatic updates yet. New versions will be posted on the Releases page.
- A file too big for the Recycle Bin can't be recycled. In that case Windows
  shows its own "permanently delete?" warning rather than DClutter deleting it
  silently.
- Swipes work best on a precision touchpad, which most laptops from the last
  several years have. On other touchpads, a short pause ends each swipe, and
  the shelf moves one folder per swipe instead of following your fingers.
